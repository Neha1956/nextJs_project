# 🚀 Next.js Admin Dashboard

A simple admin dashboard built using **Next.js, Zustand, MUI**, and **DummyJSON API**.  
It includes user and product management with authentication, search, and pagination.

---

## ✨ Features

### 🔐 Authentication
- Login using DummyJSON API
- Token stored using Zustand
- Protected routes

### 👤 Users Module
- Users list from API
- Search users
- Pagination (Next / Prev)
- Single user details page

### 🛍️ Products Module
- Products list from API
- Search products
- Pagination support
- Single product details page

### 🎨 UI
- Material UI (MUI)
- Fully responsive design
- Clean card & grid layout

---

## 🧠 State Management
Used **Zustand** for:
- Auth state
- Users data
- Products data
- Search & pagination

---

## ⚡ API Used
- https://dummyjson.com/users
- https://dummyjson.com/products
- https://dummyjson.com/auth/login
